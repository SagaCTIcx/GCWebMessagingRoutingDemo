# Genesys Cloud Web Messaging Demo Pages

This repository contains a collection of standalone HTML demo pages used to present different Genesys Cloud Web Messaging scenarios, integration concepts, and customer experience use cases.

## Purpose

The purpose of this repository is to keep multiple independent demo pages in one place and publish them through GitHub Pages for easy internal or customer-facing demonstrations.

## Repository structure

Each demo page is stored in its own folder and uses its own `index.html` file.

Example structure:

```text
/
├─ index.html
├─ assets/
│  └─ images/
├─ 3rd-Party-Platform/
│  └─ index.html
├─ CoBrowse-sagadoobeograd/
│  └─ index.html
